# automatic-card-shuffler
Automatic card shuffler robot

Battery powered automatic card shuffler

model:
- 2 stacks of cards located on each side of a middle hole

prototype:
- laser cut hull, model to be added soon (10cmx6cmx5cm)
- 2x servos with rubber tips for pulling bottom most cards from stacks into hole at random intervals
- random intervals defined by script installed onto a raspberry pi pico
